# 完整功能盤點

| 環節 | 這次交付 | 正式營運需要的延伸 |
| --- | --- | --- |
| 營業設定 | 單店、固定餐期與桌型、兩小時佔位、提前 30 分鐘截止 | 業主可設定公休、特別營業日、當日封桌、緩衝清潔時間、可預約天數 |
| 客人訂位 | LINE 查詢、自動分桌或相鄰併桌、聯絡資料、訂位編號、查詢本人訂位 | 訪客導覽、餐廳交通與地址、特殊需求、十三人以上包場 |
| 變更與取消 | 重新檢查桌位，改期失敗保留原訂位，取消立即釋出 | 設定免責取消期限、候位遞補、限制重複訂位或頻繁未到 |
| 訂位通知 | LINE 立即回覆結果 | 行前提醒、臨時關店群發、通知失敗可重試 |
| 到店交接 | 分時人數、依人數備餐、聯絡方式、報到、未到、客人主動分享定位 | 現場客與電話訂位、實際離席記錄、桌位調整、無網路時的手動流程 |
| 店務管理 | 依日期、餐期、入座時間檢視桌況、分時文字名單與圖像動畫 | 店員與業主分權、操作稽核、訂位與未到趨勢、報表匯出 |
| 資料與上線 | LINE 簽章、事件去重、私有資料檔、業主金鑰、Pages 展示 | 上線平台與真實 LINE 驗收、備份演練、資料留存與刪除、監控及告警 |

若店家準備對外營運，最先補公休與封桌，接著補電話與現場訂位。這四種情況都會影響同一份桌位庫存。提醒與候位遞補則可在共用庫存穩定後加入。
